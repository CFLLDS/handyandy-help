# Send the confirmation

**Screen: Bookings, Calendar**

Every booking has a ready-written confirmation you can send to the customer. It sets out what is booked, when, and what it will cost.

1. Find the booking in the **Calendar**.
2. Select **Confirmation**. The text opens under the booking.
3. Select **Copy to clipboard**.
4. Paste it into an email, a text or a letter to the customer.
5. Select **Hide confirmation** to close it.

Handy Andy does not send the confirmation for you. It is sent from your own email or phone, so you can add a line of your own if you want to.
