# What has been collected

**Screen: Service, second panel**

This panel is the whole ledger, not the window you chose above. The first panel is a projection; this one is receipts.

## The two headline figures

| Figure | Meaning |
|---|---|
| **Collected** | Money received, and the number of jobs it came from |
| **Delivered and unpaid** | Work that has been done but not yet paid for, and the number of jobs |

The bar underneath shows what share of delivered work has been paid for.

## How it arrived

Payments split by method: card reader, cash, bank transfer and so on. Use this to see how much is still being handled as cash, and to reconcile against the bank.

## Where the record comes from

This shows which records the figures were taken from, so you can see how much still rests on appointment notes and how much is in Handy Andy bookings.

## Using it

If **Delivered and unpaid** is growing, ask finance to work through the [Invoicing](../invoicing/index.md) screen. Most unpaid work is work that has not been invoiced yet, not customers who will not pay.
