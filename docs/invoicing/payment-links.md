# Payment links

**Screen: Invoicing, on the job**

A payment link opens the invoice on the customer's own phone, with no sign-in, and lets them pay by card. It is also how the handyperson takes payment at the door.

## Create and send a link

1. On the job, select **Create a payment link**.
2. Select **Copy**.
3. Paste it into a text or email to the customer.

The job shows when the link was created and by whom.

## Replace a link

If a link went to the wrong place, select **Replace**. Your browser asks you to confirm, because the link already sent to the customer will stop working. The new link replaces it.

## Close a link

When a link is no longer needed, select **Close this link**. Your browser asks you to confirm. The customer will no longer be able to open it.

!!! warning "Links are counted for a reason"
    Anyone holding the link can see the household's details on the invoice. Send it only to the customer, replace it at once if it goes astray, and close links you no longer need.

## Check whether it has been paid

Select **Check whether it has been paid**. Handy Andy asks the payment provider and shows the answer on the job.
